# Madilynns Craft Coffee Shop

Static site for Madilynns Craft Coffee Shop, St. Cloud, FL. Plain HTML, CSS and JavaScript, no build step.

- Pages: `index.html`, `menu.html`, `food.html`, `beans.html`, `our-story.html`, `visit.html`
- Shared: `styles.css`, `script.js`
- Notes and pre-launch checklist: `docs/IMPROVEMENTS.md` (not deployed)

Deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main` (or the working branch).

Preview locally: `python3 -m http.server` and open http://localhost:8000.
